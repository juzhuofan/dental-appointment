## 复验入口

项目根目录运行：

```powershell
npm.cmd run test:unit
npm.cmd run test:regression-ui
```

界面入口会先构建管理端，再启动专用端口的管理端构建预览与小程序 H5 预览，结束后停止本次启动的进程。需安装项目依赖、Node.js 24.18.0 和 Microsoft Edge，端口 6186、6190 应空闲。它只运行模拟回归，不调用旧的演示登录或真实业务数据库。

后端本轮执行 JDK 17 / Maven 离线 `test`，显式设置 `ai.live=false`、`ai.database=false`。完整输出保存在 `.local/fix-backend-tests.log`。客户端、界面和构建记录分别见 `.local/fix-client-tests.log`、`.local/fix-ui-tests.log`、`.local/fix-admin-build.log`、`.local/fix-miniapp-build.log` 和 `.local/fix-h5-build.log`。
