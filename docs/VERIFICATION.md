## 复验

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Verify-Local.ps1
```

复验需要后端、管理端及患者 H5 均已启动。更新代码并重新构建前，先停止项目服务，避免 Windows 锁定后端 JAR 文件。
